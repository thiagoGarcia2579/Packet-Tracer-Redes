# TP12 - Trunking entre Switches

## Objetivo
Implementar enlaces trunk entre switches Cisco para permitir la comunicación entre múltiples VLANs a través de un mismo enlace físico, manteniendo la segmentación de red.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Configuración de VLANs en switches Cisco
- Creación de enlaces trunk entre switches
- Asignación de puertos a distintas VLANs
- Configuración del protocolo de trunking (802.1Q)
- Verificación de comunicación entre dispositivos de distintas VLANs
- Pruebas de conectividad extremo a extremo

---

## Funcionamiento del trunking

El trunking permite:

- Transportar tráfico de múltiples VLANs por un solo enlace físico
- Mantener etiquetas VLAN (802.1Q)
- Interconectar switches sin perder segmentación lógica
- Optimizar el uso de enlaces entre dispositivos

---

## Resultados obtenidos

- Se establecieron correctamente enlaces trunk entre switches
- Las VLANs se mantuvieron separadas lógicamente
- Se logró comunicación entre switches con múltiples VLANs
- El tráfico fue correctamente etiquetado y distribuido
- La red funcionó sin pérdida de segmentación
