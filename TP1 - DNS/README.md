# TP1 - DNS y Resolución de Nombres

## Objetivo
Comprender la configuración básica de redes y el funcionamiento del sistema de resolución de nombres mediante DNS, verificando conectividad entre dispositivos.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Configuración básica de red en Cisco Packet Tracer
- Asignación de direcciones IP a dispositivos
- Pruebas de conectividad mediante ping
- Configuración de servidor DNS
- Creación de registros DNS tipo A
- Creación de alias CNAME
- Resolución de nombres de dominio
- Verificación de comunicación entre hosts

---

## Funcionamiento de DNS

DNS permite:

- Traducir nombres de dominio a direcciones IP
- Facilitar el acceso a servicios de red
- Evitar el uso directo de direcciones IP
- Centralizar la gestión de nombres en la red

---

## Resultados obtenidos

- Se configuró correctamente la red básica
- Se verificó conectividad entre dispositivos
- Se resolvieron nombres mediante DNS
- Se establecieron registros A y CNAME
- Se logró comunicación entre hosts mediante nombres

---
