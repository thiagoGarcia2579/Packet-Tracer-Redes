# TP3 - HTTP y DNS

## Objetivo
Configurar servicios de HTTP y DNS para permitir el acceso a páginas web mediante nombres de dominio, integrando la resolución de nombres con el acceso a servicios web.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Configuración de servidor HTTP
- Creación de una página web básica
- Configuración de servidor DNS
- Registro de entradas DNS tipo A
- Registro de alias mediante CNAME
- Resolución de nombres de dominio
- Acceso a páginas web mediante hostname
- Verificación de conectividad entre clientes y servidores

---

## Funcionamiento de HTTP y DNS

El sistema permite:

- HTTP: acceso a páginas web mediante navegador o cliente
- DNS: traducción de nombres de dominio a direcciones IP
- Integración entre resolución de nombres y servicios web
- Acceso simplificado a recursos de red

---

## Resultados obtenidos

- Se configuró correctamente el servidor HTTP
- Se creó una página web accesible desde la red
- Se configuró el servidor DNS
- Se resolvieron nombres de dominio correctamente
- Se logró acceso a la web mediante hostname en lugar de IP

---

## Conceptos aplicados

- HTTP (HyperText Transfer Protocol)

- Resolución de nombres
