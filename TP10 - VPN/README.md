# TP10 - VPN Site-to-Site

## Objetivo
Implementar una VPN Site-to-Site utilizando IPsec en routers Cisco, con el objetivo de establecer comunicación segura entre dos redes a través de un canal cifrado sobre una red pública.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Configuración de routers Cisco 2811
- Definición de políticas de seguridad IPsec
- Configuración de túneles VPN Site-to-Site
- Establecimiento de claves de autenticación
- Configuración de tráfico interesante (interesting traffic)
- Verificación de cifrado de datos entre redes
- Pruebas de conectividad entre sedes

---

## Funcionamiento de la VPN

La VPN Site-to-Site permite:

- Crear un túnel seguro entre dos redes remotas
- Cifrar el tráfico entre ambas redes
- Autenticar los extremos del túnel
- Proteger la información en tránsito sobre redes no seguras

---

## Resultados obtenidos

- Se estableció correctamente el túnel VPN IPsec
- El tráfico entre redes fue cifrado exitosamente
- Se logró comunicación segura entre sedes
- Se verificó el funcionamiento del túnel ante pruebas de conectividad
- La configuración de seguridad fue aplicada correctamente
