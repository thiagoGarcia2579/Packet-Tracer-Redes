# TP9 - Routing Dinámico (RIP y EIGRP)

## Objetivo
Configurar protocolos de enrutamiento dinámico RIP y EIGRP en routers Cisco para permitir el intercambio automático de rutas entre distintas redes.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Configuración de routers Cisco
- Implementación del protocolo RIP
- Implementación del protocolo EIGRP
- Configuración de interfaces seriales
- Publicación de redes en los protocolos de routing
- Verificación de tablas de enrutamiento
- Pruebas de conectividad entre redes remotas
- Análisis de métricas y selección de rutas

---

## Funcionamiento del routing dinámico

El routing dinámico permite:

- Intercambio automático de rutas entre routers
- Adaptación a cambios en la topología
- Selección de rutas óptimas según métricas
- Reducción de configuración manual

---

## Resultados obtenidos

- Se estableció comunicación entre redes distintas
- Los routers aprendieron rutas automáticamente
- Se verificó el funcionamiento de RIP
- Se verificó el funcionamiento de EIGRP
- La red reaccionó correctamente ante cambios de topología
- Se confirmaron tablas de enrutamiento dinámico

---

## Conceptos aplicados

- Routing dinámico
- RIP (Routing Information Protocol)
- EIGRP (Enhanced Interior Gateway Routing Protocol)
- Tablas de enrutamiento
- Métricas de red
- Routers Cisco
- Interconexión de redes
