# TP7 - Sockets en Python

## Objetivo
Implementar comunicación cliente-servidor utilizando sockets en Python, comprendiendo el funcionamiento de conexiones TCP y el manejo de puertos en sistemas de red.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Programación de un servidor en Python utilizando sockets
- Programación de un cliente en Python
- Establecimiento de conexión TCP entre cliente y servidor
- Envío y recepción de mensajes
- Uso de puertos para comunicación
- Verificación de conexiones activas con Netstat
- Análisis de procesos y puertos en uso

---

## Funcionamiento de sockets

Los sockets permiten:

- Comunicación entre procesos en red
- Intercambio de datos entre cliente y servidor
- Uso de protocolos como TCP y UDP
- Gestión de conexiones mediante puertos

---

## Resultados obtenidos

- Se estableció comunicación exitosa entre cliente y servidor
- Se enviaron y recibieron mensajes correctamente
- Se verificaron conexiones activas en el sistema
- Se identificaron puertos utilizados por la aplicación
- Se comprendió el funcionamiento básico de redes a nivel de aplicación
