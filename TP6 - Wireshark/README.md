# TP6 - Wireshark y Análisis de Tráfico

## Objetivo
Analizar el tráfico de red utilizando Wireshark para comprender el comportamiento de los protocolos y el intercambio de paquetes en una red.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Captura de paquetes con Wireshark
- Análisis de tráfico HTTP
- Inspección de segmentos TCP y UDP
- Identificación de direcciones IP origen y destino
- Seguimiento de conversaciones entre hosts
- Interpretación de cabeceras de protocolos
- Filtrado de tráfico por protocolo

---

## Funcionamiento del análisis de tráfico

El análisis de tráfico permite:

- Visualizar el flujo de datos en la red
- Identificar problemas de comunicación
- Entender el comportamiento de protocolos
- Detectar conexiones activas
- Analizar seguridad y rendimiento

---

## Resultados obtenidos

- Se capturaron paquetes correctamente
- Se identificaron protocolos en uso
- Se analizaron comunicaciones HTTP
- Se comprendió el funcionamiento de TCP y UDP
- Se interpretó el intercambio de paquetes en la red

---
