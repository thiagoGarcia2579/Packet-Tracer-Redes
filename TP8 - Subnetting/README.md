# TP8 - Subnetting y Direccionamiento IP

## Objetivo
Comprender y aplicar técnicas de subnetting para el diseño y optimización de redes IP, realizando cálculos de subredes, hosts disponibles y direcciones de broadcast.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Identificación de clases de direcciones IP
- Conversión de direcciones a formato binario
- Cálculo de subredes
- Determinación de máscaras de red
- Cálculo de hosts disponibles por subred
- Identificación de dirección de broadcast
- División eficiente de redes en subredes más pequeñas

---

## Funcionamiento del subnetting

El subnetting permite:

- Dividir una red grande en redes más pequeñas
- Optimizar el uso de direcciones IP
- Mejorar la organización de la red
- Reducir el tráfico de broadcast
- Aumentar la eficiencia en la asignación de IPs

---

## Resultados obtenidos

- Se realizaron correctamente los cálculos de subredes
- Se identificaron rangos válidos de hosts
- Se determinaron direcciones de broadcast
- Se optimizó el uso de direcciones IP
- Se aplicaron correctamente máscaras de subred

---

## Conceptos aplicados

- Subnetting
- Máscara de red
- Dirección IP (IPv4)
- Broadcast
- Hosts
- Clases de redes (A, B, C)
- Cálculo binario
