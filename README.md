
# Cisco Packet Tracer 

Repositorio con trabajos prácticos y laboratorios de redes realizados en Cisco Packet Tracer.

## Contenido

### TP1 - DNS y Resolución de Nombres

* Configuración de red
* Ping entre dispositivos
* Resolución de nombres
* Registros DNS A y CNAME

### TP2 - DHCP

* Configuración de servidor DHCP
* Asignación dinámica de IPs
* Configuración automática de hosts
* Verificación de conectividad

### TP3 - HTTP y DNS

* Configuración de servidor HTTP
* Acceso web mediante IP
* Resolución DNS para páginas web
* Acceso mediante hostname

### TP4 - FTP

* Configuración de servidor FTP
* Creación de usuarios y permisos
* Acceso remoto mediante FTP
* Gestión y transferencia de archivos
* Verificación de conectividad

### TP5 - Mail Server

* Configuración de SMTP y POP3
* Creación de dominio y cuentas de correo
* Configuración de clientes de mail
* Envío y recepción de correos electrónicos

### TP6 - WireShark y Análisis de Tráfico

* Captura y análisis de paquetes
* Inspección de tráfico HTTP
* Análisis de segmentos TCP y UDP
* Interpretación de protocolos de red

### TP7 - Sockets en Python

* Programación cliente/servidor
* Conexiones mediante sockets
* Verificación de conexiones con Netstat
* Análisis de puertos y procesos activos

### TP8 - Subnetting y Direccionamiento IP

* Clases y máscaras IP
* Conversión binaria
* Cálculo de subredes
* Hosts y broadcast
* División de redes

### TP9 - Routing Dinámico (RIP y EIGRP)

* Configuración de routers Cisco
* Enrutamiento dinámico con RIP
* Enrutamiento dinámico con EIGRP
* Configuración de interfaces seriales
* Verificación de rutas y conectividad
* Análisis de métricas y caminos de red

### TP10 - VPN Site-to-Site

* Configuración de VPN IPsec
* Encriptación de tráfico entre redes
* Configuración de routers Cisco 2811
* Verificación de túneles VPN
* Comunicación segura entre sedes

### TP11 - VLANs y Segmentación de Red

* Configuración de VLANs en switches
* Segmentación de redes
* Asignación de puertos a VLANs
* Verificación de conectividad
* Administración de tráfico entre hosts

### TP12 - Trunking entre Switches

* Configuración de enlaces trunk
* Comunicación entre VLANs
* Configuración de switches Cisco
* Verificación de conectividad entre hosts
* Administración de tráfico VLAN
