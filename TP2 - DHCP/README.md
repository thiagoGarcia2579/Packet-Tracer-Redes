# TP2 - DHCP

## Objetivo
Configurar un servidor DHCP para asignar direcciones IP de forma automática a los dispositivos de la red, reduciendo la configuración manual y evitando conflictos de IP.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Configuración de servidor DHCP en Cisco Packet Tracer
- Definición de rangos de direcciones IP
- Configuración de gateway predeterminado
- Configuración de DNS en el servicio DHCP
- Asignación automática de IP a hosts
- Renovación y verificación de direcciones IP
- Pruebas de conectividad entre dispositivos

---

## Funcionamiento de DHCP

DHCP permite:

- Asignar direcciones IP automáticamente
- Evitar conflictos de IP en la red
- Centralizar la administración de direcciones
- Configurar parámetros de red automáticamente (gateway, DNS)

---

## Resultados obtenidos

- Se configuró correctamente el servidor DHCP
- Los hosts recibieron IP automáticamente
- Se verificó la asignación dinámica de direcciones
- La red funcionó sin configuración manual de IP
- Se comprobó la conectividad entre dispositivos

---

## Conceptos aplicados

- DHCP (Dynamic Host Configuration Protocol)
- Asignación dinámica de IP
- Gateway
- DNS
- Redes LAN
- Cliente/Servidor
