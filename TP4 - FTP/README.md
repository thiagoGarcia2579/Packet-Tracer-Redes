# TP4 - FTP

## Objetivo
Configurar un servidor FTP para permitir la transferencia de archivos entre clientes dentro de la red, gestionando usuarios, permisos y acceso remoto.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Configuración de servidor FTP en Cisco Packet Tracer
- Creación de usuarios y asignación de permisos
- Acceso remoto al servidor mediante FTP
- Subida y descarga de archivos
- Gestión de directorios en el servidor
- Verificación de conectividad entre cliente y servidor
- Pruebas de autenticación de usuarios

---

## Funcionamiento del servicio FTP

El protocolo FTP permite:

- Transferencia de archivos entre cliente y servidor
- Gestión de archivos en directorios remotos
- Autenticación de usuarios
- Acceso controlado a recursos compartidos

---

## Resultados obtenidos

- Se configuró correctamente el servidor FTP
- Se crearon usuarios con permisos adecuados
- Se logró transferencia de archivos exitosa
- Se verificó acceso remoto desde clientes
- El servicio funcionó correctamente dentro de la red

---
