# TP5 - Mail Server

## Objetivo
Configurar un servidor de correo electrónico utilizando protocolos SMTP y POP3, permitiendo el envío y recepción de mensajes entre clientes dentro de la red.

---

## Desarrollo del práctico

Durante este trabajo práctico se realizó:

- Configuración de servidor de correo (Mail Server)
- Configuración de protocolos SMTP y POP3
- Creación de dominios de correo
- Creación de cuentas de usuarios
- Configuración de clientes de correo electrónico
- Envío de correos entre usuarios
- Recepción y lectura de mensajes
- Verificación de conectividad del servicio

---

## Funcionamiento del servicio de correo

El sistema de correo electrónico permite:

- Enviar mensajes mediante SMTP
- Recibir mensajes mediante POP3
- Gestionar cuentas de usuario en un dominio
- Facilitar comunicación asíncrona entre usuarios de red

---

## Resultados obtenidos

- Se configuró correctamente el servidor de correo
- Se crearon cuentas de usuarios funcionales
- Se enviaron y recibieron correos sin errores
- Se verificó el funcionamiento de SMTP y POP3
- Se logró comunicación entre clientes de correo

---

## Conceptos aplicados

- SMTP (Simple Mail Transfer Protocol)
- POP3 (Post Office Protocol)
- Servidor de correo
- Cliente de correo electrónico
- Dominios de red
- Comunicación en red
